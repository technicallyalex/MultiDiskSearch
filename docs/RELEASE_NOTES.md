# MultiDiskSearch 1.0.0

Initial release for 64-bit Windows and DaVinci Resolve Studio 21.2.

- Saved disks and folders with readable location names.
- Recursive search for missing project media, including nested media-pool bins.
- Duplicate-source selection and explicit review when search coverage is incomplete.
- Native Resolve relinking with target verification and retry support.
- Local thumbnails, clip/path filters, status filters and progress indicators.
- Rounded MDS identity with a gradient-shadow S and matching blue interface.
- Windows setup wizard with bundled runtime, Resolve registration and uninstaller.

See USER_GUIDE.txt for operation and QA_REPORT.md for validation coverage.
