# MultiDiskSearch 1.1.0

- Search independent drives in parallel with automatic worker scheduling and per-location progress.
- Build a persistent file index in a local folder of your choice. Settings shows its disk usage and offers refresh and rebuild controls.
- Keep the index current while MultiDiskSearch is open. Index-first mode scans disks for filenames with no usable indexed match.
- Scope searches to the current timeline or the entire project.
- Check for and install future stable releases in place through Settings, with Windows administrator approval.
- Use the combined search toolbar and themed Settings panel.

Cached matches require source review. Timeline scope covers direct audio and video sources. Relinking a shared Media Pool item updates every timeline that uses it.

# MultiDiskSearch 1.0.0

Initial release for 64-bit Windows and DaVinci Resolve Studio 21.2.

- Saved disks and folders with readable location names.
- Recursive search for missing project media, including nested media-pool bins.
- Duplicate-source selection and explicit review when search coverage is incomplete.
- Native Resolve relinking with target verification and retry support.
- Local thumbnails, clip/path filters, status filters and progress indicators.
- Rounded MDS identity with a gradient-shadow S and matching blue interface.
- Windows setup wizard with bundled runtime, Resolve registration and uninstaller.

See USER_GUIDE.txt for operation and QA_REPORT.md for validation coverage.
