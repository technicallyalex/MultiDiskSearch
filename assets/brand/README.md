# Application identity

Approved direction: rounded blue MDS, with the S extending from behind the D as a darker gradient shadow. Reference: design/branding/variations/MDS-A-rounded-shadow-v1.png in the development project.

The mark, wordmark lockup and badge are transparent native SVG assets traced from the approved sheet's letter contours. They preserve the rounded geometry without substituting a font or retaining the sheet's background. The S uses a native SVG gradient behind the D. The header has an accessibility name. No tagline is included.

Keep the S behind the D, preserve the horizontal gradient, and keep clear padding around the lockup. The three SVGs ship with the application; original design sheets stay in design/branding/. tools/trace_brand.py regenerates the vector outlines from the approved reference using contour tracing and subpixel simplification.
